# Песочница генератора карты

Фрактальная гекс-карта: мир-тор с верхним уровнем 1000 км, каждый гекс делится на 100 детей (масштаб ×10) вплоть до 1 м.
Любой тайл — детерминированная функция (сид, рецепт мира, адрес), поэтому стыки сходятся, а порядок открытия не важен.

```
npm run sandbox        # http://localhost:8765/biomes.html , прототипы: /town.html (город), /walls.html (стены на гексах 1 м), /quarter.html (векторный квартал)
npm run sandbox:test   # эталонный снимок + проверка стыков в node
```

## Устройство

Зависимости направлены сверху вниз; генератор (всё, кроме `view/`) не знает о DOM и запускается в node.

| Папка | Что внутри |
|---|---|
| `src/core/` | геометрия гексов, хэш и шум, связные компоненты — чистые функции |
| `src/world/` | рецепт мира (`config.js`), тор и периодический шум (`topology.js`), биомы |
| `src/features/` | содержимое мира: рельеф и биомы, реки, ручьи, дороги; общий механизм линейных объектов (`linear.js`) |
| `src/rules.js` | конвейер правил: единый список в порядке выполнения |
| `src/gen/` | движок (этапы, пачки, кэш) и слой правок мастера |
| `src/checks/` | общие проверки: запрещённые соседства, непрерывность рек и дорог |
| `src/generator.js` | точка входа генератора |
| `src/view/` | карта (окно, масштаб, мышь), отрисовка, панель управления |
| `src/town/` | прототипы города (`town.html`) , стен на тактической сетке (`walls.html`, `walls.js`: дома под углом 30°·k, стены вектором, закрытые рёбра) и векторного квартала (`quarter.html`, `quarter.js`: план 100 м → клетки 1 м): кварталы 100 м из ручных модулей и шаблонов районов, улицы решают рёбра (пока отдельно от генератора) |
| `tests/` | эталонный снимок (`golden.json`) и запуск проверок |

## Правила конвейера

- `stage: top` — видит весь верхний уровень; `draft` — свою пачку и уровень выше; `final` — свою пачку и черновики 6 соседей.
- Правило видит мир только через `ctx` и пишет в `c.data[ns]`; случайность — своя у каждого правила (`ctx.rand`, `ctx.rng`, `ctx.noise`).
- Порядок внутри этапа влияет на результат.

## Рефакторинг

Каждый шаг без изменения поведения обязан давать тот же хэш снимка (`npm run sandbox:test`).
Если поведение меняется сознательно — обновить `tests/golden.json` после проверки стыков.
